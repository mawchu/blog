RTL 的語言設定

例如阿拉伯（Arabic, 縮寫 ar）、波斯（Farsi, 縮寫 fa）等就是屬於 RTL（Right to left） 由右至左的書寫方向，窺探一下語言設定的檔案可知一二：

產出的 HTML 就可以輕鬆制定書寫方向的樣式了：

透過 HTML attribute dir="rtl" 設定由右至左， dir="ltr" 設定由左至右的書寫方向以外，還可以結合 SCSS 的 @include 來自定義分別左與右的樣式避免破版。
